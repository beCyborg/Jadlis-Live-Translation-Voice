# Jadlis Live Translation Voice

Голосовой переводчик живого разговора в браузере: русский ⇄ польский, испанский, чешский или английский.
Телефон лежит между двумя людьми, экран поделён пополам, верхняя половина повёрнута к собеседнику.
Человек говорит — приложение показывает, как распознало речь, крупно выводит перевод на половине
другого человека и озвучивает его.

**Сайт:** https://becyborg.github.io/Jadlis-Live-Translation-Voice/

## Режимы

В настройках, группа «Режим»:

- **Перевод:** оба направления (RU ⇄ PL), только с русского (RU → PL) или только на русский (PL → RU).
  В одностороннем режиме фразы на другом языке пропускаются, как шум.
- **Слушать:** «Сам» — телефон слушает всё время и переводит после паузы. «По кнопке» — первое нажатие
  большой кнопки внизу включает запись, второе отправляет на перевод всё, что сказано между нажатиями.
  Паузы внутри записи фразу не обрывают.

## Как устроено

- Сервера нет. Браузер сам ходит в ElevenLabs и Anthropic с ключами пользователя (BYOK); ключи
  лежат только в `localStorage`. Строгий CSP пускает страницу только к этим двум API.
- **Распознавание** — ElevenLabs Scribe v2 Realtime, новый сеанс на каждую реплику: в одном сеансе
  Scribe запоминает первый язык и молча переводит на него остальное (`spike/RESULTS.md`).
  Звук в новый сеанс идёт только с начала речи — тишина перед речью тоже сбивает язык.
- **Перевод** — Claude Sonnet 5.5 (или Haiku 5.5): один запрос исправляет ошибки распознавания,
  решает направление и переводит. Ответ начинается с метки `ru→pl⟩`, озвучка стартует с первой части фразы.
- **Озвучка** — Eleven v4 Turbo, HTTP-стрим по предложениям; темп — `playbackRate` с сохранением высоты.
  Эхо собственного перевода отсекается по совпадению текста.

## Демо-ключи

Если в секретах репозитория заданы `VITE_DEMO_ANTHROPIC_KEY` и `VITE_DEMO_ELEVEN_KEY`, сборка вшивает
их в сайт, и он работает без ввода ключей. Их видит любой, кто откроет код страницы, поэтому у демо-ключей
должен быть лимит трат. Чтобы выключить демо: удалить оба секрета и перезапустить деплой.

## Разработка

```sh
npm install
npm run dev      # http://localhost:5173/Jadlis-Live-Translation-Voice/
npm run check
npm run build
```

`spike/` — замеры: язык Scribe (`scribe.mjs`), озвучка (`gen-tts.mjs`), бенч перевода (`bench.ts`),
сквозной тест с поддельным микрофоном (`e2e.mjs`, режимы — `e2e-modes.mjs`).
